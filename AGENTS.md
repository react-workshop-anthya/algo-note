# Algorithm Practice Entry Point

For algorithm tutoring, practice planning, exercise setup, or reviewing a
learner's solution, read [.agents/skills/leetcode-teacher/SKILL.md](.agents/skills/leetcode-teacher/SKILL.md)
before acting. If the skill is not listed by the runtime, read that file directly.
It is the canonical teaching policy for this repository.

Read [roadmap.md](roadmap.md) and the latest dated log in `review_log/` to find
the active problem and checkpoint. Do not treat an old log's "Next Session" as
the current queue. Inspect the relevant exercise before claiming its status.

Keep responsibilities separate:

- Teaching preferences: the local skill.
- Practice schedule and queue: `roadmap.md`.
- Actual attempts, assistance, verification, and next checkpoint: `review_log/`.
- Career goals: [the career roadmap](../plans/OKR/big-tech-18mo-roadmap.md).

Conversation follows the learner's language. New durable artifacts are English.
Preserve learner code and unrelated changes. A request to review an exercise
is not permission to replace its implementation. Do not commit or push unless
requested. General repository maintenance is distinct from a tutoring session.
