## Mistakes To Watch

- Initialize a dict key before incrementing it, or use `counts.get(key, 0) + 1`.
- For Two Sum, return previous index first and current index second.
- Fixed-size alphabets can make space O(1), but time is still O(n + m).
- In frequency count problems, `set` is not enough when duplicate counts matter.
