## Mistakes To Watch

- Keep number of strings `n` separate from maximum word length `k`:
  sorting-key grouping is O(nk log k) time and O(nk + n) auxiliary space.
- Value lists store original-string references; new sorted keys use character
  storage. The implementation must satisfy the output contract itself.
- Container area uses the shorter endpoint and distance between indices.
- Greedy correctness discards dominated pairs. It does not predict which next
  heights are larger, nor promise that each pointer move improves the area.
- Equal positive endpoints give a smaller area on the immediate next move;
  zero endpoints can remain at zero. Better pairs may appear further inside.
