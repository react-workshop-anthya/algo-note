# Six-Month Interview Preparation Roadmap

Goal: rebuild algorithm fluency and start attempting interviews within six
months while keeping practice focused on pattern recognition, clean
explanations, and spaced review.

## Operating Rules

- Prioritize pattern recognition over raw problem count.
- Start each problem with the brute-force idea before optimizing.
- Record time complexity, space complexity, edge cases, and review notes.
- Redo missed or hinted problems without looking at the solution.
- Use Easy problems to warm up or isolate a pattern; use Medium problems as the
  main training level.

## Weekly Baseline

- 3-4 Easy or review problems
- 2 Medium problems
- 1 review session
- 1 pattern note update

If time is limited, keep the minimum viable week:

| Day | Work |
| --- | --- |
| Monday | 1 new problem with full trace |
| Tuesday | Redo the previous problem without hints |
| Wednesday | 1 new problem |
| Thursday | Pattern note update and 1 quick Easy problem |
| Friday | 1 Medium problem |
| Saturday | 2 problems and weekly review |
| Sunday | Rest or redo missed problems |

## Phase 1: Month 1 - Restore Fundamentals

Goal: recover syntax fluency, rebuild confidence, and reconnect common patterns.

Focus patterns:

- Hash Map / Hash Set
- Two Pointers
- Sliding Window
- Binary Search
- Stack

Weekly target:

- 3-4 Easy problems
- 2 Medium problems
- 1 review or redo session

Suggested sequence:

1. Two Sum
2. Contains Duplicate
3. Valid Anagram
4. Group Anagrams
5. Container With Most Water
6. Longest Substring Without Repeating Characters

## Phase 2: Months 2-3 - Medium-Focused Pattern Training

Goal: make Medium problems the default practice level.

Focus patterns:

- Sliding Window
- Intervals
- Monotonic Stack
- Heap / Top K
- BFS / DFS
- Tree recursion

Weekly target:

- 1 Easy warm-up
- 4-5 Medium problems
- 1 redo problem
- 1 pattern note update

## Phase 3: Month 4 - Graph, DP, and Backtracking

Goal: cover higher-pressure interview topics without jumping straight into
unstructured Hard problems.

Focus patterns:

- Graph BFS / DFS
- Topological Sort
- Union Find
- Basic Dynamic Programming
- Backtracking

Suggested DP sequence:

1. Climbing Stairs
2. House Robber
3. Coin Change
4. Longest Common Subsequence

## Phase 4: Month 5 - Timed Practice and Mock Interviews

Goal: solve Medium problems in 35-45 minutes with interview-style explanation.

Weekly target:

- 2 timed practices
- 3-4 Medium problems
- 1 mock interview or spoken walkthrough
- Redo past missed problems

Practice checklist:

- Ask clarifying questions.
- Explain brute force first.
- Explain the optimization.
- Write clean code.
- Analyze time and space complexity.
- Test edge cases.

## Phase 5: Month 6 - Interview Loop and Weak-Point Review

Goal: begin real interview attempts while maintaining problem-solving rhythm.

Weekly target:

- 2-3 Medium problems
- 1 weak-area problem
- 1 mock or interview retrospective
- Review notes after each real interview

Avoid opening too many new patterns in this phase. Focus on consistency,
communication, and filling known gaps.
